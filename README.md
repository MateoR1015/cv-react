# Hoja de Vida en React

Proyecto de hoja de vida desarrollado con React y Vite.

## Componentes

- App
- Header
- About
- Skills
- Education
- Experience
- Contact
- Footer

## Conceptos de React utilizados

- Componentes reutilizables
- Props
- Arreglos y `.map()`
- `useState`
- Eventos con `onClick`
- Renderizado condicional
